# 当前状态

## 项目定位

本项目是仅使用合成数据的临床前研究原型，不是医疗器械、电子病历、诊断或处方系统。

## 可演示能力

- 预置和手工合成病例；
- 病历编辑、不可变修订、事务、并发保护和审计元数据；
- 合成资料导入、解析、资料检索和资料引用定位；
- 受约束的结构化模型参考与来源一致性校验；
- 诊疗复核和医生最终确认；
- public-demo 只读边界。

SQLite 最新 migration 为 12。

## 实验性能力

语音识别链路属于实验性语音功能。Windows 语音便携版支持本机录音、15秒自动停止、离线转写、设备错误提示和连续分段录入；语音建议必须经过医生处理，不自动写入病历。轻量便携版和 public-demo 不启用麦克风，手工录入始终可用。

## 明确未完成

项目不提供真实患者数据、真实教材效果、临床验证、临床准确率、诊断、处方、漏诊排除或生产可用性结论，也不支持医院系统部署。

## 数据与医学边界

所有病例、资料和演示内容均为合成数据。模型参考、资料引用和复核结果只供医生参考，不能替代医生判断。公开快照不得包含密钥、真实个人信息、原始音频、完整转写、完整模型响应或内部路径。
