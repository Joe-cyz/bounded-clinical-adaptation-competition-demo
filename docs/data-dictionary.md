# 数据字典总览

本字典描述合成数据原型中的公开对象和安全边界。所有示例均为合成数据，不能用于真实临床记录。

| 对象 | 用途 | 公开边界 |
| --- | --- | --- |
| SyntheticCase | 预置合成病例 | 合成 ID、版本、专科和就诊类型 |
| Encounter | 一次合成接诊 | 状态、病例引用和时间元数据 |
| EncounterRecord | 结构化病历 | 版本化字段、状态和修订引用 |
| LiteratureDocument | 合成资料 | 名称、版本、格式和处理状态 |
| Evidence | 资料引用定位 | 资料 ID、分段 ID 和安全摘录位置 |
| ModelReference | 结构化模型参考 | 项目、事实、支持 ID、状态和 provenance |
| Review | 诊疗复核 | 规则结果、决定和确认状态 |
| AuditEvent | 工程审计 | 类型、对象 ID、版本和聚合元数据 |

病历正文、完整转写、完整模型响应、密钥和原始资料正文不进入通用审计或公开快照。
