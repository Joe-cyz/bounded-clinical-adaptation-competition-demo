# 病历数据字典

## 记录结构

病历采用版本化 EncounterRecord 结构，包含：

- 合成患者名称和受控上下文；
- 主诉、现病史、既往史、个人史和家族史；
- 过敏史、当前用药、危险信号和近期变化；
- 生命体征、体格检查和辅助检查；
- 患者教育事实和待补充信息；
- 每个字段的内容与状态。

状态区分 PROVIDED、UNKNOWN、NOT_APPLICABLE 和 PENDING_PHYSICIAN_CONFIRMATION。只有经过 Schema、PII、并发和事务校验的修订才能成为当前修订。

## 持久化边界

旧修订不可变，当前修订通过接诊指针关联。待确认语音建议和未确认的模型参考不会进入病历保存载荷。数据库不保存原始录音、完整转写或完整模型响应。
