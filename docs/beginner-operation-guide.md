# 医生端入门操作指南

本指南用于本地合成数据演示。它不指导真实诊疗，也不接收真实患者、真实教材或真实音频。当前以手工录入为可靠入口；实验性语音功能只在明确配置并由医生主动操作时出现。

## 一、启动

首次运行先安装依赖，再启动标准 Next.js 开发服务器：

~~~text
pnpm install --frozen-lockfile
pnpm dev
~~~

打开 `http://localhost:3000`。默认是 `public-demo` 只读模式，不需要密钥，不初始化可写数据库，也不调用真实模型或语音服务。演示只使用公开合成病例，不要填写密钥或改变模型服务配置。

## 二、医生主路径

1. 首页选择“开始接诊”，只选择合成病例。
2. 在病历记录页查看只读人口学信息和结构化病历。
3. 手工编辑合成内容，点击“保存病历”，确认页面显示新的修订号。
4. 进入“模型参考”，阅读确定性病历摘要。摘要只复述已保存事实，不是诊断、处方或治疗意见。
5. 进入“资料”。资料导入、解析、资料检索和资料引用已在合成资料范围内可用；只选择项目提供的合成资料。
6. 进入“诊疗复核”，处理必填项和待核对项。
7. 医生逐项确认，勾选最终声明并完成记录。

## 三、语音功能（实验性）

如果页面显示语音能力已配置，可以点击一次“开始录音”，朗读合成内容，再点击“停止录音”。识别结果会先显示为待医生处理建议；只有医生明确写入并保存后才会进入病历。手工录入仍是当前可靠入口。

## 四、资料操作

资料页显示资料名称、版本、格式和处理状态。资料准备好后，可在资料范围内输入检索词并查看结果和引用定位。引用是工程定位信息，不代表医学结论；不要上传真实教材或院内材料。

## 五、复核与确认

“必填项”表示结构化病历仍缺少完成规则所需的信息；“待核对”表示需要医生逐项判断。这些状态不是漏诊检测，也不是临床安全认证。只有必填项清零、待核对项已处理且医生声明完成后，接诊才会进入已确认状态。

## 六、数据边界

项目只使用合成数据。不要输入真实姓名、电话、身份证号、地址、健康记录或录音，不要复制完整模型响应或资料正文到公开报告。模型参考只供医生参考，不能替代医生判断。
