# 本地演示手册

本手册用于合成数据的本地演示。医生主路径和研究治理路径彼此独立；任何页面都不应被描述为真实电子病历或临床部署。

## 医生主路径

~~~text
首页 → 合成接诊 → 病历记录 → 模型参考 → 资料检索 → 诊疗复核 → 医生确认
~~~

页面只展示患者上下文、病历、结构化参考、资料状态和复核结果。模型参考只供医生参考，诊疗复核只检查结构化完整性和人工确认状态。

## 启动与停止

在项目根目录执行：

~~~text
pnpm demo:start
~~~

等待 DEMO_START_READY 后打开本地页面。演示结束后停止服务并等待 DEMO_START_STOPPED。不要并行启动多个服务，不要删除项目目录，不要填写外部凭据。

## 合成资料

资料导入、解析、资料检索和资料引用在合成范围内可用。导入资料后等待处理状态完成，再进行检索和展开引用。引用用于定位合成资料摘录，不构成医学结论。真实教材和院内材料不属于本演示范围。

## 实验性语音

语音是实验性功能。只有医生明确点击录音后才请求本地能力，结果先进入待医生处理状态。手工录入是当前可靠入口，未经医生确认的建议不会进入病历。

## 只读演示

公开演示不会创建接诊、保存病历、写入审计、调用模型服务或调用语音服务。遇到只读提示时停止写入操作，不要通过刷新或重复点击绕过边界。

## 研究治理页面

研究页面只用于展示确定性测试、规则状态和安全导出边界。不得把研究结果介绍为临床验证、诊断或生产性能结论。
