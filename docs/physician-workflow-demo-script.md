# 医生端主路径演示脚本

全程只使用合成病例和合成资料。预计 5—8 分钟。该流程是临床前工程原型演示，不代表临床验证、诊断、处方或医院部署。

## 演示前

在项目根目录执行 pnpm demo:start。确认页面显示本地合成数据边界，再进入“开始接诊”。不要填写 API key，不要上传真实材料，不要录制真实患者声音。

## 主路径

1. 首页：说明这是合成数据原型，并点击“开始接诊”。
2. 接诊选择：选择一个合成病例并进入病历记录。
3. 病历记录：查看只读患者信息，编辑一项合成病史并保存。
4. 模型参考：查看已保存事实的确定性摘要。它只供医生参考，不是诊断或治疗意见。
5. 资料检索：进入资料页，选择已准备的合成资料，进行检索并查看资料引用定位。
6. 诊疗复核：返回模型参考并进入诊疗复核，处理必填项和待核对项。
7. 医生确认：确认每项内容，勾选最终声明并完成记录。

## 实验性语音功能

只有在本地语音已配置时才演示。医生主动点击开始和停止，结果先作为待医生处理建议；未确认的建议不进入病历，原始音频和完整转写不进入公开材料。手工录入是当前可靠入口。

## 公开演示

public-demo 只读。页面可以浏览合成病例、模型参考、资料状态和复核结果，但不能保存病历、作出确认、写入审计或调用外部服务。

## 讲解边界

模型参考、资料检索和复核规则只说明工程机制与人工确认流程，不证明医学正确性、临床准确率、诊断能力、处方能力、漏诊排除或生产可用性。
