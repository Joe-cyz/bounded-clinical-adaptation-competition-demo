# DeepSeek 模型服务适配器

## 目的与边界

适配器在统一模型服务端口下提供受控的结构化参考通道。它只接受服务端生成的合成病例和合成资料投影，不接受浏览器直接传入的运行模式、来源、预算或密钥。

public-demo 默认只读，在数据库初始化和网络调用前阻断写入与模型服务。local-research 需要服务端明确启用、固定预算和格式校验；失败时不自动重试、不切换模型、不降级。

## 请求与输出

请求只包含必要的合成事实、允许的资料证据 ID 和版本化结构契约。响应必须是严格 JSON，并通过项目 Schema、ID、语言、PII、引用和 provenance 校验。模型只返回结构化项目和允许的证据 ID；最终资料引用由服务端从安全资料投影生成。

密钥只存在于服务端环境，不进入浏览器、审计、导出、日志或错误消息。完整请求、完整响应、模型正文和资料正文不写入运行记录。

## 失败关闭

超时、认证失败、非成功状态、非法 JSON、结构不符、语言越界、PII 或来源不一致都返回固定安全错误。错误不回显 URL、路径、密钥、请求正文或底层堆栈。

## 责任边界

该适配器只用于合成数据工程验证。模型参考只供医生参考，不证明模型质量、医学正确性、临床准确率、诊断能力、处方能力或生产可用性。
