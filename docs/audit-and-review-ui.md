# 审计与复核界面

该页面用于展示合成数据流程中的安全状态和医生确认边界。它不是临床审计系统，也不替代组织内部的医疗质量流程。

## 界面原则

- 先展示接诊、病历修订和复核状态，再展示可展开的技术元数据；
- 只展示安全 ID、版本、状态和聚合计数，不展示病历正文、完整模型响应、密钥或原始音频；
- 阻断项必须明确返回病历补充，不能用“忽略全部”绕过；
- 最终确认只在必填项清零、待核对项已处理且当前修订匹配时出现；
- public-demo 只读，不渲染决定、确认和保存控件。

## 复核语义

复核检查的是结构化完整性、字段状态和医生确认动作。它不是漏诊检测，不判断诊断正确性，也不自动生成治疗或处方建议。
