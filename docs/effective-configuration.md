# Effective configuration compiler

## 目的

配置编译器将版本化合成病例、机构安全核心、批准的专科策略和可选的合成医生画像编译为一次结构化参考所需的显式配置。它是纯函数，不读取界面状态、数据库、环境变量或未指定的“最新”配置。

## 治理顺序

1. 机构安全核心；
2. 专科与接诊类型策略；
3. 合成医生画像的允许偏好；
4. 单次医生操作。

医生偏好不能删除安全必填项、改变免责声明、扩大资料范围或绕过确认边界。

## 输出

EffectiveGenerationConfig 只包含可序列化的病例、策略、画像、安全规则、栏目顺序、呈现偏好、版本摘要和稳定配置键。相同输入得到相同配置；任何来源版本变化都会改变定位信息。

GENERIC 与 BOUNDED 共享安全核心和批准策略，只在允许的呈现偏好上不同。两种模式都会补齐合法栏目，避免配置遗漏安全要求。

## 失败关闭

策略缺失、不匹配、未批准、重复匹配，或画像缺失、非活动状态时，编译返回固定规则 ID，调用方不得继续生成。输入 Schema 和安全核心不变量失败同样阻断。

该编译器只服务合成数据的本地工程原型，不实现学习、持久化扩展或临床验证。
