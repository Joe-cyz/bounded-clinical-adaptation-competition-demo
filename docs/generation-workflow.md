# 结构化参考生成流程

## 输入

服务端从合成病例和当前可信病历修订生成安全事实投影，并根据允许的专科、就诊类型和资料范围建立请求上下文。客户端不能覆盖运行模式、来源、预算或安全版本。

## 处理

模型服务只接收固定结构的请求，返回严格 JSON。服务端随后校验 Schema、事实 ID、资料证据、项目角色、语言边界、PII 和 provenance，并由服务端生成最终资料引用。任何失败都以受控错误返回，不保存完整响应。

## 输出

成功结果只进入待医生参考状态，不自动写回病历。医生如需把内容纳入病历，必须在病历编辑页明确处理并保存新修订。public-demo 在数据库和网络调用前保持只读阻断。
