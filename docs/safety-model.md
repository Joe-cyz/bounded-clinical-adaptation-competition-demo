# 安全模型

## 核心边界

系统只处理合成数据。服务端在每条写入或外部调用路径上检查运行模式、权限、Schema、PII、来源、预算和当前修订。

## 纵深控制

- public-demo 在数据库初始化前拒绝写入；
- local-research 只接受合成病例；
- 资料引用只能来自安全投影；
- 模型参考必须通过固定结构、语言和 provenance 校验；
- 语音结果先作为待医生处理建议；
- 病历修订不可变，事务失败时不产生部分状态；
- 审计只保存安全元数据，不保存正文或密钥。

## 医学边界

安全模型是工程控制集合，不是临床安全认证。它不证明诊断、处方、漏诊排除、临床准确率或生产可用性。
